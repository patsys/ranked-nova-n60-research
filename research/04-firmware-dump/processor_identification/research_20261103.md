# External processor-identification search — 3 November 2026

No exact processor identification was established by this search.

Subsequent user transcription from the review photo, corrected and confirmed:

- `RY7203 N48C-C 2214-CC`
- `RY1206 N48C-C 2214-CB`

These replace the earlier erroneous `RY723`/`RY126` transcription. They are
user-read package markings from a reviewed board, not a tool-verified photograph
of the actual connected board. RY7203 is consistent with the observed ry72xx
bootloader naming. Manufacturer documentation, exact variant/package semantics
and assignment of the second chip to RGB have not been independently confirmed.
No meaning is assigned to the trailing codes here.

- Official ISO-DE product page:
  https://ranked.gg/products/nova-n60-mechanical-gaming-keyboard-iso-de
  No exact part number found in the inspected page.
- Firsthand teardown:
  https://www.techpowerup.com/review/ranked-nova-n60-keyboard/4.html
  The reviewer explicitly describes the USB microcontrollers as not easily
  identifiable and repeats only the generic 32-bit ARM claim. Public HTML was
  retrieved with a normal HTTP request after the web reader failed. This does
  not prove that the chip marking is erased or that another PCB revision is
  identical. The chip is visible in the PCB photo; visibility is distinct from
  successful identification.
- Downloaded, inspected public photos 8 and 9 show the PCB and switch sockets.
  The main image is not sufficient to read a trustworthy part number here.
  Requests for the separate closer photos returned HTTP403. Browser and desktop
  inspection tools could not initialize due to missing kernel assets.
- YouTube: https://www.youtube.com/watch?v=Uc3IJlnCB3g (We Do Tech) and
  https://www.youtube.com/watch?v=1GtUT6gtB4A (MechTech Keyboards).
  Public video metadata/descriptions were inspected. Captions were advertised
  but returned empty responses; full video frames were not inspected. Therefore
  this is not a claim that no video contains a readable chip marking.
- GitHub code search found no indexed exact `ry72xx_boot_usb` match. General
  `ry72xx` matches were unrelated. Repository searches found no relevant Nova N60
  QMK port in their returned results. These are limited search observations,
  not proof that no other work exists.
